# MyOS

MyOS — открытая Linux-ориентированная операционная система для мобильных устройств.

## Цель проекта

Создать быстрый, приватный и настраиваемый Linux-смартфон, который со временем сможет:

- запускать Linux-приложения;
- поддерживать Android-приложения без виртуальной машины;
- предоставлять набор инструментов безопасности по желанию пользователя;
- иметь собственный мобильный и desktop-интерфейсы;
- давать пользователю контроль над обновлениями, приватностью и режимом разработчика.

## Текущий прототип

MyOS 0.5 — загрузочный x86-прототип для компьютера или виртуальной машины. Он уже
загружается в QEMU, поддерживает клавиатурный ввод, таймер, виртуальную файловую
систему, командный терминал и первый цветной визуальный интерфейс.

## Принципы

- Open source
- Privacy by choice
- Свобода настройки
- Безопасность без лишних ограничений
- Возможность отката обновлений
