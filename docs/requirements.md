# Требования MyOS 0.1

## Главная цель

Создать минимальный прототип MyOS, который запускается на компьютере или в виртуальной машине.

## Обязательный результат первого этапа

- Загрузка Linux-системы.
- Базовый пользовательский набор программ.
- Первый собственный интерфейс.
- Документированная структура проекта.

## Целевые архитектуры

- x86_64 — для первого прототипа.
- ARM64 — для будущего портирования на телефон.

## Не входит в MyOS 0.1

- Поддержка Android-приложений.
- Desktop mode.
- Набор инструментов безопасности.
- Портирование на конкретный телефон.
