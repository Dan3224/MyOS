# MyOS Window Layer

MyOS 1.0 now presents Files, System, App Launcher, and Notes as windows on top
of the desktop. Each window has an accent-coloured frame, title bar, visual
depth shadow, and a consistent `H CLOSE` control.

Keyboard navigation stays deliberately simple for this stage: use `F`, `S`,
`A`, or `N` to open a window and `H` to return to the desktop. This is the
foundation for the next interaction milestone: focus management and a PS/2
mouse cursor.
