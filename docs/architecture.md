# Архитектура MyOS 0.1

## Слои системы

1. **Boot и kernel** — загрузка Linux-ядра и базовая работа с оборудованием.
2. **System** — системные службы, конфигурация и запуск пользовательской среды.
3. **UI** — собственный графический интерфейс поверх Wayland в будущих итерациях.
4. **Build** — сценарии, которые собирают образ MyOS для тестирования.

## Стартовая платформа

Первый прототип разрабатывается и тестируется на x86_64 в виртуальной машине. Архитектура должна допускать будущее добавление ARM64.

## Будущие направления

- Android compatibility layer
- Mobile UI
- Desktop mode
- Security tools as optional packages
